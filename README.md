# Machine Learning Based Multi-Criteria Evaluation of Six Developed Countries for Mobility Decision Support

## Overview

This research project presents a machine learning-based framework for evaluating and ranking six developed countries using multiple socio-economic and quality-of-life indicators. The study aims to support mobility and migration decision-making through data-driven analysis and predictive modeling.

The project integrates machine learning techniques with multi-criteria decision analysis (MCDA) to provide a structured and intelligent evaluation system for comparing countries based on important migration-related factors.

---

## Objectives

- Evaluate six developed countries using multiple indicators
- Apply machine learning techniques for comparative analysis
- Support mobility and migration decision-making
- Develop a ranking framework based on socio-economic factors
- Provide data-driven insights for international mobility planning

---

## Features

- Multi-criteria country evaluation
- Data preprocessing and normalization
- Machine learning-based prediction and analysis
- Comparative ranking system
- Data visualization and reporting
- Decision support framework
